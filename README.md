# Black Friday 2026: Meerdanlicht – Lighto LED-kaarsenset 6 stuks

Landingspagina met een scroll-gestuurde productanimatie (Apple-stijl beeldreeks op canvas, GSAP ScrollTrigger).

- `index.html`: pagina, merkstijl en content
- `shared/`: gedeelde engine (`scrub.js`) en layout (`base.css`)
- `frames/d` en `frames/m`: WebP-beeldreeksen voor desktop en mobiel (uit een Higgsfield AI-video)
- `img/`: geoptimaliseerde productfoto's

Statische site, geen build. Broncode wordt beheerd in `jaap-mercuriushub/blackfriday-radiator` (map `meerdanlicht/`)
en hiernaartoe geëxporteerd met `tools/split.sh`.
